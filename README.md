# 元素之间 · 化学扑克牌

静态网页，无运行时依赖。`dist/` 可直接部署到静态托管服务。

本地启动：在当前目录运行 `python -m http.server 4173 --directory dist`，然后打开 http://localhost:4173。

## 已实现

- A 质量竞技与 B 化学接龙；一位真人与两位仅使用自身手牌的电脑玩家。
- 72 / 108 张临时牌库，来自 1,800 张、19 种元素的总牌池。
- 配方种子混合抽牌 / 纯随机不放回抽牌。默认每局轮换 9 种候选元素，减少扩展元素相互割裂。
- 卡面单质取色、自动排序、合法组合提示、图鉴、牌局记录、本机自动保存。
- 有机物基团连键，单 / 双 / 三键；图同构判定接受等价节点互换。
- 质量使用整数千分值计算，避免浮点比较误差。

## 规则边界

合法性以随附图鉴为准；不调用模型猜测物质是否存在。原子组可自由重组，非真实反应模拟。未实现联网多人。
有机物氢合并在基团上，不要求逐个画 C—H；不区分立体异构。图鉴可以在 `dist/chemistry.mjs` 扩充。
牌库配比为可调试玩参数，并非经验证的最优配比。随机配方仅保证总体组牌基础，不保证个人手牌可完整拆分。

## 验证

运行 `node tests/engine.test.mjs`。测试包含质量比较、牌数守恒、B 的残余组与两圈重置、随机牌库、结构等价性及多局模拟。

浏览器检查：为 `tests/browser.test.mjs` 提供环境变量 `PLAYWRIGHT_MODULE`（playwright-core 的 index.mjs 绝对路径）及 `CHROMIUM_PATH`（浏览器路径），并先启动本地服务器。

试玩模拟（72 局，固定种子，每局上限 600 回合）：A 的 36 局全部结束；B 的 36 局中 27 局结束。B 的配方混合模式为 23/24，纯随机为 4/12。该结果只是电脑策略下的测量，不代表真人对局胜率；B 不保证有限回合结束，纯随机模式尤其可能拖长。保留用户约定的两圈重置规则，没有私自增加强制结算。

浏览器支持时提供只读牌桌信息、暂选组合两项 WebMCP 工具。当前普通 Chromium 不提供原生 WebMCP 上下文，原生工具验证不可用；不影响手动游玩。
