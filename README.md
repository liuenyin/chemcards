# 元素局 · 多人化学扑克牌

2—6 人联网房间。一名房主创建，朋友通过房间码或链接加入；全部准备后开始。保留一人对两位电脑的本机练习。

## 本次重做

- 服务器维护房间与完整牌局，D1 持久化；每位玩家只获取自己的手牌。
- 所有出牌在服务端重新校验回合、手牌和质量；结构局还强制校验有机物连接关系与形式电荷，快速局按配方出牌。
- 乐观并发控制防止同时提交和重复请求导致重复出牌；刷新、断线后可凭本机保存的入座凭证返回。
- 86 种元素、598 条内置物质记录。修正硝基苯和硫化银，补回遗漏的氯化铵、卤代烃等；甘油、草酸可以通过别名搜索。
- 规范化学式保留数据中的常用写法；匹配用的原子计数不再用于生成无机物显示式。未成物质的原子组显示为“元素 × 数量”。水合物的前置系数不作下标。
- 未收录的物质可附资料提交，经全体玩家确认后加入当前房间，明确标记为房间约定，不冒充自动化学认证。
- 独立原子手牌：点击抬牌、横划连续选牌、Shift 区间选择、整组选牌拖向桌面；排序保留选牌。手机手牌区可滚动。
- 发牌、抽牌、出牌动效；B 模式可直接点击牌堆摸牌。未轮到自己时可以预选，提示组合按需打开。
- 真正的单原子自由画布：拖动、单/双/三键、擦键、撤销重做、自动补氢；完整结构图同构验证接受等价画法。
- 四位数字房间码（0000—9999），空号选择和冲突重试；24 小时无人访问的房间回收。刷新不改变服务器保存的回合截止时间。
- 默认自由随机，从 1800 张牌池不放回抽取 72/108 张；采用最大余数法分配整数张数，图鉴中可查看实际概率。
- B 默认开启“解套”：无任何合法组合时才可单原子领出，旧 C 进入弃牌堆，新原子留给下家。可在房间设置中关闭，恢复严格接龙。
- 按需展开成牌候选抽屉；独立音效、音量和震动设置；本浏览器合成图鉴（含练习）；含牌池中不超过 4 张元素的物质有轻量稀有提示。

## 本地运行

需要 Node.js 24（本地开发使用内置 SQLite），npm。

```sh
npm install
npm run build
npm run dev
```

打开 http://127.0.0.1:4173。`scripts/dev.mjs` 使用与云端相同的 Worker 和 API；数据库保存在忽略提交的 `.sites-runtime/rooms.sqlite`。在两个独立浏览器或无痕窗口中可测试双方交互。

## 发布结构

- `dist/` 顶层文件：浏览器源码。
- `server/worker.mjs`：房间与对局 API；静态资产打包嵌入 Worker。
- `dist/server/index.js`：由构建生成，未纳入源码提交。
- `.openai/hosting.json`：Sites 项目及逻辑 D1 绑定 `DB`。
- `db/schema.ts` / `drizzle/`：数据库结构和生成迁移。生产环境由发布流程应用迁移，不在请求中创建表。

## 明确边界

有机物不区分立体异构；结构局的内置有机物需要结构校验。房间自行批准的物质只按配方校验，并在提交时向所有人说明。
限时由服务器判断。任意入座玩家的请求会结算已到期回合：A 自由领出代出一张原子，A 跟牌过牌，B 摸牌。在线设备每 1.4 秒同步，因此当前玩家离线不阻塞其他人；全员离线时不后台连续跑局，再次访问时结算一个到期回合。不启用限时时，需等待当前玩家恢复或由房主结束本局。
内置库不是全部已知化合物，房间共同确认是扩展机制，不是科学检索认证。
内置记录未逐条完成外部科学审定；回归测试只覆盖已列出的资料样例及图结构一致性。无稳定同位素的元素使用固定游戏质量，不能解读为标准原子量。
物质配比和电脑策略仍是可调整的游戏参数。开启解套、每回合都选择出牌时，总手牌数严格减少；玩家一直选择摸牌仍可能长局。严格 B 可能包含无内置配方可消耗的元素；两圈重置不会消除这种手牌，请按房间偏好选择规则。

原子量参考 CIAAW；KSCN 可核对 PubChem CID 516872：https://pubchem.ncbi.nlm.nih.gov/compound/516872。
本轮化学修订参考：[硝基苯](https://pubchem.ncbi.nlm.nih.gov/compound/7416)、[硫化银](https://pubchem.ncbi.nlm.nih.gov/compound/Silver-sulfide)、[六羰基钨](https://webbook.nist.gov/cgi/cbook.cgi?ID=C14040110)、[三氟化氮](https://pubchem.ncbi.nlm.nih.gov/compound/Nitrogen-trifluoride)。
